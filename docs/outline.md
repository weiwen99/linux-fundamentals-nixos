# 《Linux 入门基础：从 NixOS 开始》结构

## 定位

- 读者：完全没接触过 Linux，也没写过程序的人。
- 目标：独立装好 NixOS；用它做日常工作与开发；能做一台 Linux 服务器的日常运维；会安全地使用 AI Agent。
- 写法：实践优先。每章十五分钟内跑出结果，理论只解释“为什么这样做”。不设页数目标，A4 开本。
- 桌面：Hyprland 与 Niri 为主线，GNOME 与 KDE Plasma 作为已知选项介绍。
- 安装路线：虚拟机、实体机、VPS 三条并行，读者按手上条件选。

## 贯穿全书的两条线

1. **旧工具 → 新工具**。先讲任何 Linux 上都有的 `find`/`grep`/`sed`/`du`，再给 `fd`/`rg`/`sd`/`dust` 的现代替代与配方。系统坏掉、只有 busybox 时，能救命的只有旧工具。
2. **Unix 文化**。每章一则短注（小工具、文本流、约定、手册、社区礼节），第三章集中讲一次。目的是让读者能“猜”出没见过的命令怎么用。

## 每章模板

```
导语（三句话：解决什么问题，做完能干什么）
1  十分钟上手：一条能跑的命令 + 输出解读
2  拆开看：命令、参数、配置文件分别是什么
3  再来三个练习：换目录、换参数、故意做错一次
4  为什么这样设计（短，不超过一页）
5  旧工具与新工具
6  练习（3–5 题，含一道“故意破坏再修好”）
7  检查点
```
