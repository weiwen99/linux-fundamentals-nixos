# 《Linux 入门基础：从 NixOS 开始》结构

## 定位

- 读者：完全没接触过 Linux，也没写过程序的人。
- 目标：独立装好 NixOS；会用它做日常工作与开发；能做一台 Linux 服务器的日常运维；会安全地使用 AI Agent。
- 写法：实践优先。每章开头十分钟内能跑出东西，理论只解释"为什么这样做"，不单独成篇。
- 开本：A4，页数由内容决定，不设配额。
- 桌面：Hyprland 与 Niri 为主线，GNOME 与 KDE Plasma 作为已知选项介绍。
- 安装路线：虚拟机、VPS、实体机三条并行，读者按手上条件选。

## 贯穿全书的两条线

1. 旧工具 → 新工具。先讲任何 Linux 上都有的 `find`/`grep`/`sed`/`du`，再给 `fd`/`rg`/`sd`/`dust` 的现代替代与配方。理由：连不上网、进不了系统、只有 busybox 的时候，能救命的只有旧工具。
2. Unix 文化。不是独立的历史课，而是分散在每章开头的一则短注，加上第二章的集中讲解，说明这些工具为什么长这样、社区为什么这样说话。

## 每章模板

```
导语（三句话：这一章解决什么问题，做完能干什么）
1. 十分钟上手：一条能跑的命令 + 它输出的解读
2. 拆开看：命令、参数、配置文件分别是什么
3. 再来三个练习：换个目录、换个参数、故意做错一次
4. 为什么这样设计（短，不超过一页）
5. 旧工具与新工具
6. 练习（3–5 题，含一道"故意破坏再修好"）
7. 检查点
```
